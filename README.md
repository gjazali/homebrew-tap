# Homebrew Tap

Homebrew formulae for [gjazali](https://github.com/gjazali) projects.

## Installing

You can find the formula name under the [Formula](https://github.com/gjazali/homebrew-tap/tree/main/Formula) directory. Use the file names minus the `.rb` extension. You can do the installation with:

<pre>
brew install gjazali/tap/<b><i>formula_name</i></b>
</pre>

Or, if you prefer to tap first:

<pre>
brew tap gjazali/tap
brew install <b><i>formula_name</i></b>
</pre>
